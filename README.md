# MP Tourism Linktree Prototype

A lightweight static HTML page with quick links to Madhya Pradesh Tourism Board resources, policies, social channels and visitor information.

## Preview locally

Open `Index.html` in a browser. The page has no build step and does not require a server.

## Maintenance notes

- Review all external links periodically and verify that official policy/document links still point to the intended current version.
- The page is a convenience link directory, not an official source of policy text. The linked official MPTB website remains authoritative.
- External links opened in new tabs use `rel="noopener noreferrer"`.
